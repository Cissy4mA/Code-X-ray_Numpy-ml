3. Search / 检索

3.1 Module Search / 模块搜索

Search the 13 algorithm modules. Each result shows the module's own README (e.g., numpy_ml/neural_nets/README.md) in a scrollable box. / 搜索 13 个算法模块，每个结果在滚动框中展示该模块目录下的 README 原文（如 numpy_ml/neural_nets/README.md），不显示代码。

3.2 Algorithm Search / 算法搜索

Search returns top-k algorithm classes / 算法分类 (a complete algorithm). Each class card lists all its member functions on the right. / 返回前 k 个完整算法分类，每张卡片右侧列出该分类下的全部成员函数。
